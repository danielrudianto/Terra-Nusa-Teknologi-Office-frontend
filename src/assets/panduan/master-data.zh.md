# 主数据

在所有单据中反复使用的参照数据。

主数据是供应商、客户、员工、物品与设备的唯一来源。所有单据均从此处选择，而非重新
录入——因此在此处的一次修正会应用到各处。

正因为共用，此处的错误会扩散。拼写有误的供应商名称，会出现在提及它的每一张采购订单、
采购记录与报表中。

## 新增数据之前

**先搜索。**这是本菜单中最重要的规则。

重复条目是主数据中最常见的问题，且其后果不会立即显现。“PT Fuji Bolt”与“PT. Fuji Bolt
Indonesia”在每份报表中都会被视为两家不同的供应商，其交易历史就此一分为二，却无人
察觉。

各子菜单的搜索框会跨列查找。请花十秒钟确认该记录确实尚不存在。

## 供应商

任何向公司开具账单的一方：企业与个人均可。

| 字段 | 说明 |
|---|---|
| 前缀 | PT、CV、UD、个人等 |
| 名称 | 不含前缀；前缀另有专门字段 |
| 地址、城市、省份 | 会打印在采购订单单据上 |
| 税号 | 涉及代扣税款时需要 |
| 电话、电子邮箱 | 用于联系 |
| 销售商品 | 便于创建采购订单时查找 |
| 服务区域 | 其覆盖范围 |

请将**前缀**填入其专属字段，不要并入名称。系统在显示时会重新拼接；若前缀也被录入名称
中，结果会变成“PT PT Fuji Bolt”。

## 客户

公司向其开具账单的一方。字段与供应商相仿，但不含商品与服务区域。

对于需以税务发票开票的客户，**客户税号为必填**。缺少税号则无法开具税务发票，开票随之
搁置。

## 员工

领取工资单的人员数据。

| 字段 | 说明 |
|---|---|
| 姓名、身份证号 | 身份证号用于工资单 |
| 出生日期 | |
| 职位、部门 | 会打印在工资单上 |
| 税务类别 | TK/0 至 K/3，决定免税额 |
| 入职日期 | |
| 地址、电话、电子邮箱 | |

此处的**税务类别**会带入工资单，并决定第 21 条预扣税。类别依据员工在纳税年度开始时的
状况，而非当下。

## 物品

用于采购订单的商品目录。适用于从列表中选择商品的采购订单类型——C、F、G、5.1.1 与
5.1.6。

系统提供 **CSV 导入**功能，可一次录入大量商品。导入后请检查结果：格式偏离的行可能会
作为新物品录入，而非更新既有条目。

## 设备

用于设备租赁类采购订单（B 类）的重型设备目录：名称、类别、容量与品牌。

这是**可供租赁的设备类型**目录，与记录公司自有设备的**资产**菜单不同。租赁设备不登记
为资产。

## 交易对方

**费用**菜单中的收款方——例如电力公司、税务局或房东。之所以与供应商分开，是因为他们
不开具采购订单，也不供应物资。

## 删除主数据

请勿删除已被单据使用过的记录。旧单据会失去其引用，按供应商或员工分组的报表也将变得
不完整。

仅删除创建有误且从未使用过的条目。对于有问题的供应商，系统提供黑名单标记——这优于
删除，因为历史记录得以完整保留。
