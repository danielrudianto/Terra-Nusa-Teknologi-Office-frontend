# 其他收入

记录并非来自项目开票的收款。

本菜单用于服务销售以外的收入：银行利息、特许权使用费、股息、尾差等。向客户就项目
工作开具的账单**不**在此记录——那属于销售发票。

## 何时使用本菜单

当款项在没有销售发票的情况下入账时，使用**其他收入**：账户利息、退款、尾差调整。

当款项来自向客户开具的工作账单时，使用**销售发票**。

## 填写数据

本表单的所有字段均为必填——没有可选项。

| 字段 | 说明 |
|---|---|
| 日期 | 确认收入的日期 |
| 付款日期 | 款项实际到账的日期 |
| 收入类型 | 决定其会计科目 |
| 账户 | 收款的 AKN 账户 |
| 交易对方 | 付款方 |
| 交易对方备注 | 简要说明对方身份 |
| 金额 | 最低 0.01 |
| 收入说明 | 说明该款项的来由 |

日期与付款日期常常不同。账户流水以**付款日期**为准，因此请按银行对账单上的日期
填写，而非单据上的日期。

### 收入类型

| 类型 | 适用 |
|---|---|
| 利息 | 利息收入 |
| 特许权使用费 | 特许权使用费收入 |
| 股息 | 股息收入 |
| 尾差 | 四舍五入差额 |
| 其他 | 其他收入 |

与费用模块一样，若存在更贴切的类型，请避免选择**其他**。

## 保存之后

点击某一行可查看明细：金额、日期、说明、交易对方，以及记录创建的时间。

三点菜单提供**查看收入记录**与**删除收入记录**。删除操作会以执行者的账户名义记入
活动历史。

列表可按日期范围筛选。搜索框会在说明、交易对方与发票编号中查找。
