# 招聘应聘者

应聘者名单及其参加考试所用的链接。

应聘者**并非员工**，也没有账号。标识其身份的是令牌本身——一条一次性生成、数日内有效的长链接。

## 谁可以打开

与题库相同，仅限**人力资源部**与**企业主**。其中存有尚未成为员工者的个人资料。

## 登记应聘者

点击**登记应聘者**。仅需填写**姓名**与**男/女**。

其余内容——称呼、出生日期、住址、联系方式——由应聘者在考试中自行填写。事先收集这些资料，正是此功能意在省去的工作。

### 粘贴列表

若姓名已存在于表格或消息中，请点击**粘贴列表**并一次性粘贴全部。可接受的格式：

```
Budi Santoso, L
Siti Aminah, P
Andi Pratama
```

仅有姓名可以；姓名后加 L/P，以**逗号、分号或制表符**分隔亦可。空行会自动跳过。

### 性别

用于邀请消息中的**称谓**——Bapak 或 Ibu。留空则为「Bapak/Ibu」。

刻意不从姓名推测：向公司外部人士发出的第一条消息若称谓有误，所留下的印象难以挽回。

### 有效期

默认 **7 天**，可在 1 至 30 天之间调整。

自令牌生成时起算，而非自消息发出时起算。若今日生成、三日后才发送，则仅剩四天。

## 发送给应聘者

每行有三个按钮：

| 按钮 | 复制内容 |
|---|---|
| **复制链接** | 仅链接地址 |
| **复制消息** | 完整邀请消息，可直接粘贴至 WhatsApp |
| 向下箭头 | 展开消息预览 |

**复制消息**会组装完整文本：与性别相符的称谓、链接、三个考试部分，以及关于计时器的说明。

其中的时长与有效期数字**取自数据**，并非写死。各试卷时长可能不同，有效期在生成令牌时决定——承诺与实际不符的数字，会让应聘者觉得受到欺瞒。

**粘贴前请先阅读预览。** 这是发给公司外部人士的第一条消息，误发后无法从 WhatsApp 撤回。

顶部的**复制全部链接**可一次性复制所有仍在有效期内的应聘者姓名与链接。

## 状态说明

| 状态 | 含义 |
|---|---|
| 未开始 | 链接已生成，尚未打开 |
| 进行中 | 已打开，计时器正在运行 |
| 已提交 | 答案已送出 |
| 已录用 / 未录用 | 已作出决定 |

**已过期**的链接会变暗显示，而非隐藏。查阅者需要知道该应聘者曾被邀请——若从列表中消失，便会有人再次登记并生成第二个令牌。

## 应聘者打开的页面

地址为 `terrabot.alphakonstruksi.id/exam`。

有两种进入方式：自行输入令牌，或直接通过链接。两者都必要——长链接从 WhatsApp 复制时常被截断，遇到此情况的人需要一条无需索取新链接的出路。

开始之前，应聘者须确认两项准备：可制作 CAD/PDF 图纸的设备，以及稳定的网络连接。

## 需要留意

- 已过期的令牌无法恢复；请重新登记该应聘者以生成新链接
- 计时自应聘者点击「开始」起算，而非自链接发出起算
- 一位应聘者对应一个令牌；为同一人生成两次，会让其无从判断哪一个有效
