# 费用

记录并非为项目采购物资的支出。

费用涵盖运营成本：租金、水电、燃料、薪酬相关项目、罚款、银行手续费等。若所购为带
采购订单编号的项目物资，则应归入**采购**，而非此处。

## 填写流程

依次三个步骤，比采购模块简短，因为费用没有必填附件。

**基本信息 → 金额信息 → 付款信息**

## 步骤一：基本信息

| 字段 | 必填 | 说明 |
|---|---|---|
| 发票名称 | 否 | 如有正式发票则填写 |
| 收据名称 | 否 | 如凭证为收据则填写 |
| 说明 | 是 | 说明该费用的用途 |
| 费用类型 | 是 | 决定其会计科目 |
| 交易对方 | 否 | 收款一方 |
| 日期 | 是 | 预填为今日 |
| 到期日 | 是 | 预填为今日 |

发票名称与收据名称均为选填，但若确有凭证，请勿两者皆空——列表中的搜索正是依据这些
编号。

### 选择费用类型

费用类型决定该笔费用归入哪个科目，因此选错会一路影响到报表。可选项包括：

行政费用 · 广告费 · 资产维护 · 资产购置 ·
员工费用 · 设备租赁 · 燃料 · 医疗费用 · 利息 ·
物流费用 · 罚款 · 社会与社区支出 · 预付租金 ·
水电费 · 软件 · 尾差 · 交通 · 社交媒体 ·
招聘费用 · 培训费用 · 人工 · 材料 · 其他

若存在更贴切的类型，请避免选择**其他**。大量费用堆积在“其他”之下，会使报表无法
阅读。

## 步骤二：金额信息

| 字段 | 说明 |
|---|---|
| DPP | 必填，最低 0.01 |
| PBBKB | 若不适用请填 0 |
| 预扣税代码、预扣税对象名称、预扣税率 | 适用于需代扣预扣税的费用 |
| 合计 | 自动计算 |

若该费用需代扣预扣税，实际转出金额将小于合计——与采购模块相同。

## 步骤三：付款信息

收款账户：银行名称、账户名称、账号，以及付款方式（银行转账、虚拟账户或支票）。

**生成付款单**开关会在费用保存后立即生成付款单，无需再从付款菜单进入。

## 保存之后

在费用列表中点击任意一行，可查看其明细——金额构成、付款历史与收款账户。

最右侧的三点菜单提供**查看费用**与**创建付款**。创建付款仅对具备对外付款权限者
显示。

列表可按日期范围筛选，搜索框会同时在发票编号、收据、采购订单、交易对方与税务发票中
查找。
