# 活动记录

记录谁在何时、从何处更改了什么。

TerraBot 中的每一次创建、修改、审批、拒绝与删除都会记录于此。记录自动生成，任何
人都无法修改或删除——包括操作者本人。

## 何时使用本菜单

无需每日查看。当某个问题无法从单据本身得到答案时才打开：

- “这张采购订单的金额怎么变了，是谁改的？”
- “这笔付款是谁审批的？”
- “这条数据不见了，是什么时候删除的？”

## 读懂一行记录

| 列 | 含义 |
|---|---|
| 操作者 | 由谁执行 |
| 动作 | 创建、修改、审批、拒绝、删除等 |
| 模块 | 属于哪类单据 |
| IP 地址 | 来自哪台设备 |

点击某一行可查看**字段变更**：字段名称、变更前的值与变更后的值。

对于**创建**与**删除**动作，变更面板通常为空——创建时不存在“变更前”，而删除并
不改动任何数值。这是正常现象，并非记录损坏。

## 筛选

可按模块与日期范围筛选。若要追溯某一份具体单据，通常更快的做法是打开该单据并查
看其**变更历史**——内容相同，且已经过筛选。

## 有意不予记录的内容

密码与令牌**绝不会**进入本日志。此类字段在保存前会被替换为 `(已隐藏)`。

原因在于：任何有权访问本菜单的人都能读取活动记录，而记录在其中的密码等同于已经
泄露的密码。

## 它能告诉你的界限

本日志记录的是**变更了什么**，而非**为什么变更**。备注列仅在部分动作中由系统
填写。

若某项变更需要说明原因，请写在单据自身的说明中——不要指望活动记录能自行回答。

由于内容涉及工资与付款的变更，本菜单的访问权限受到限制。
