# 税务

从系统中已记录的数据提取税务汇总。

本菜单**不计算应纳税额**，也不替代账簿。它所做的是汇集采购、销售发票与工资单中已
有的数字，并按月整理，以便直接核对。

## 使用流程

在税务中心页面选择一次**期间**——月份与年份。该期间会带入所有汇总表，无需在每份
报表中重新选择。

随后打开所需的汇总表。

## 四类汇总表

| 汇总表 | 数据来源 | 用途 |
|---|---|---|
| **增值税** | 采购数据 | 进项增值税汇总 |
| **预扣税（采购）** | 采购数据 | 采购环节代扣的预扣税汇总 |
| **预扣税（工资）** | 工资单 | 员工工资的第 21 条预扣税汇总 |
| **月度报表** | 全部模块 | 涵盖整月的综合汇总 |

**月度报表**覆盖面更广：应付账款、应收账款、银行流水、资产、借款、采购与销售。通
常提交给税务顾问的正是这份报表。

## 数字的准确性取决于单据

这些汇总表读取的是已记录的内容。若上游有误，汇总也会随之出错，且不会有任何提示。

最常见的成因：

**增值税税率选错。**货运代理服务适用 1.1%，其余适用 11%。此处选错会直接带入增值税
汇总。

**预扣税代码未填。**本应代扣预扣税、但税务对象代码留空的采购不会出现在预扣税汇总
中，该笔代扣看起来仿佛从未发生。

**税务发票尚未编号。**未填写税务发票编号的销售发票会标记为**发票未开具**——这并非
系统错误，而是提醒该单据确实尚不完整。

## 税务状态

销售发票带有阶段标记：

| 状态 | 含义 |
|---|---|
| **发票未开具** | 尚未填写税务发票编号 |
| **等待收款** | 发票已开具，款项尚未到账 |
| **缺代扣凭证** | 客户已代扣预扣税，凭证尚未收到 |
| **已完成** | 全部单据与款项均已齐备 |

**缺代扣凭证**若积压，需向客户催收。没有凭证，已被代扣的税款无法抵扣——公司等于
承担两次。

## 提交给顾问之前

请就相应期间核对以下各项：

- 没有仍处于**发票未开具**状态的销售发票
- 没有本应齐备却仍处于**待处理**状态的采购
- 客户出具的代扣凭证已通过销售发票菜单录入

现在修正单据，比日后解释差额要容易得多。

## 本菜单不做的事

它不缴纳税款，不计算多缴或少缴，也不替代纳税申报。这些数字是上述工作的原始材料——
编制与申报仍须与税务顾问共同完成。
