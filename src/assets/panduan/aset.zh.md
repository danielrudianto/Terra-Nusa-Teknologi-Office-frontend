# 资产

登记公司财产并追溯其折旧。

资产是指可使用数年的有价值物品——重型设备、车辆、大型工具。易耗品与小型用品不属
于资产，应记为普通采购。

## 何时算作资产

判断标准并非价格，而是**使用年限**。在一个项目内即消耗完毕的是成本；下一个项目仍
在使用的则是资产。

资产通常通过 **5.1.1（资产购置）**类采购订单购入。在此登记资产时需引用该采购订单
编号。

## 登记资产

除销售信息外，所有字段均为必填。

| 字段 | 说明 |
|---|---|
| 资产名称 | 现场惯用的名称 |
| 说明 | 足以与同类设备区分的描述 |
| 品牌 | 例如：徐工、小松 |
| 资产类型 | 固定资产／设备／工具 |
| 位置 | 物品存放地点 |
| 折旧 | 使用年限组别，见下文 |
| 采购订单名称 | 该次购置所依据的采购订单 |
| 购买日期 | 取得日期 |
| 价值 | 取得成本 |

### 选择折旧组别

选项依照税务所采用的使用年限组别：

| 选项 | 适用 |
|---|---|
| 4 年（第 1 组） | 工具、小型设备、办公设备 |
| 8 年（第 2 组） | 车辆、家具、轻型重机具 |
| 16 年（第 3 组） | 重型机械、特定构筑物 |
| 20 年（第 4 组） | 建筑物及类似资产 |

此选择不只是一个标签。组别选错会使每年的折旧费用随之出错，并一路影响到财务报表。
若不确定，请在保存前询问会计部门——不要猜测。

## 价值与折旧

填写的**价值**为取得成本，而非当前价值。该数字不随时间变动；变动的是账面价值，而
账面价值在账簿中另行计算。

需要知道：**TerraBot 保存折旧组别，但尚未计算各期折旧费用。**该计算仍在会计系统中
进行。因此，请勿将此处的资产清单作为账面价值的依据。

## 已出售的资产

表单下方的**销售**部分为选填。资产实际售出后，填写**销售金额**与**销售日期**。

请勿删除已出售的资产。其历史仍有用处——用于追溯购置时的采购订单，以及计算处置损益。
标记销售即已足够。

## 查看与追溯

点击任意一行可打开明细。三点菜单提供**编辑资产**与**查看采购订单**——后者可直接跳
转至购置该资产的采购订单，在核对取得成本与原始单据时很有用。

搜索框会同时在名称、品牌、类型与采购订单编号中查找。
