# 报销

申请返还先行垫付的款项。

当有人以个人资金支付办公所需并申请返还时，使用报销。若款项直接由公司账户支付，则
不属于报销——应记为费用。

## 填写申请

表单在同一页面中分为三个部分。

### 明细

| 字段 | 说明 |
|---|---|
| 日期 | 申请日期 |
| 到期日 | 预计返还到账的时间 |
| 费用类型 | 与费用菜单使用同一列表 |
| 项目名称 | 承担该成本的项目 |

### 账户与付款

银行名称、账号、账户名称，以及付款方式（银行转账、虚拟账户或支票）。

此处填写的是**接收返还款的账户**，即垫付人本人的账户，而非公司账户。

### 报销明细项

按每笔支出添加一行，各含日期、说明与金额。合计由所有行自动汇总。

请按单据分行，不要合并为一个大项。一行涵盖五张单据，在审批时难以核对，出现差额时
也难以追溯。

## 审批流程

申请无法立即付款，顺序如下：

1. 创建申请
2. **审批报销**——仅限具备审批权限者
3. **创建付款**——审批通过后方可使用

在申请尚未审批、已付款或已删除期间，**创建付款**菜单保持禁用。一旦审批通过，
**审批**菜单即被禁用。

这种分离是有意为之：申请人、审批人与备款人不是同一个人。

## 审批之后

点击某一行可查看明细项、付款历史与收款账户。

若单据需要再次打印，可使用**重新打印报销单**——无需重新创建申请。
