# 账户间转账

记录公司自有账户之间的资金划转。

本菜单仅适用于**从一个 AKN 账户划转至另一个 AKN 账户**的资金——例如从主账户调拨
至项目运营账户。流向他方的资金不属于此处。

## 不适用于什么

这是最常见的混淆。若资金流向公司之外的一方，则不应使用本菜单：

| 资金流向 | 正确菜单 |
|---|---|
| 另一个 AKN 账户 | **账户间转账**（本菜单） |
| 供应商，用于结算发票 | 付款，经由采购或费用 |
| 垫付款项的员工 | 报销 |
| 员工工资 | 工资单 |

原因不仅在于条理。账户间转账**既不增加费用，也不增加收入**——资金只是换了位置。
若将支付给供应商的款项记录于此，该费用将完全不被记录，报表随之出错。

## 记录转账

单页表单，五个字段，均为必填。

| 字段 | 说明 |
|---|---|
| 日期 | 资金实际划转的日期 |
| 转出账户 | 出款的 AKN 账户 |
| 转入账户 | 收款的 AKN 账户 |
| 金额 | 最低为 1 |
| 说明 | 简要说明本次转账的用途 |

说明栏预填为**“运营现金存入”**作为起点。若用途不同，请予修改——日后追溯流水时读
到的正是这条说明，因此仅在确实属实时才保留原文。

### 转出与转入账户不得相同

已选为转出方的账户会在转入列表中自动置灰。若强行选择，将出现提示*“转出与转入账户
不得相同。”*，且无法保存。

## 删除记录

删除按钮位于每行最右侧，并会要求确认。

**仅可在当日删除。**一旦转账日期已过，该按钮将永久禁用。这是有意设计：此前日期的
流水已进入对账，事后删除会使数字不再与银行对账单相符。

因此请在保存前核对。若差错在次日才发现，请联系会计部门——更正无法通过本菜单进行。

删除也并不意味着记录消失。该记录仍会保留并标记为**已删除**，同时附有删除人与删除
时间。

## 查看明细

点击任意一行可打开其明细：

- **转账金额**——划转的数额
- **转账流向**——转出与转入账户
- **明细**——交易日期与说明
- **审计追踪**——由谁创建；若已删除，则显示删除人及时间

列表可通过起止日期按范围筛选。
