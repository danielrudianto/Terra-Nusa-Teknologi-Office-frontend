# 采购

记录供应商发票的指南。

**采购**菜单用于记录**已经收到**的供应商账单——而非订购物资。订购通过采购订单进行，
其编号将在此处被引用。

## 开始之前

请先准备：

- 该次采购所依据的**采购订单编号**
- 供应商开具的**发票**（必填，不可跳过）
- **采购订单或合同副本**（必填）
- 税务发票与收据（如有）
- 供应商的收款账户

供应商须已登记。若尚未登记，请先通过供应商菜单添加。

## 填写流程

表单分四个步骤，依次进行。只有当前步骤填写完整后，**下一步**才会启用，因此无法
跳过。

**基本信息 → 金额信息 → 附件信息 → 付款信息**

## 步骤一：基本信息

单据身份及其与采购订单的关联。

| 字段 | 必填 | 说明 |
|---|---|---|
| 发票名称 | 是 | 供应商的发票编号 |
| 收据名称 | 否 | 若收据单独出具则填写 |
| 税务发票名称 | 否 | 最多 17 个字符 |
| 供应商 | 是 | 从列表中选择 |
| 日期 | 是 | 发票日期 |
| 到期日 | 是 | 供列表中的到期筛选使用 |
| 采购订单名称 | 是 | 须符合格式，见下文 |
| 项目 | 是 | 依据采购订单编号**自动填入** |
| 单据类型 | 是 | 物资采购／其他采购 |
| 单据状态 | 是 | 就绪／待处理 |

### 采购订单编号格式

采购订单编号不可自由输入——格式是固定的：

```
0451-PO-BKS01-6.4.1
 |    |    |     +-- 成本类型
 |    |    +-------- 项目代码（4-5 位大写字母/数字）
 |    +------------- PO、SPK 或 PKS
 +------------------ 流水号（3-4 位数字）
```

可接受的成本类型：`A` `B` `C` `D` `E` `F` `G` `H1` `H2` `5.1.1` `5.1.2`
`5.1.6` `5.1.7` `5.1.12` `6.3.1` `6.3.2` `6.4.1` `6.4.2` `6.5.1`

编号正确后，**项目与成本类型会依据编号各段自动填入**。若输入后两者仍为空，说明格式
尚未匹配——请检查前段的位数或项目代码。

### 内部采购

位于底部的开关。用于内部采购，即并非为客户项目而进行的采购。只有标记为内部的采购，
日后才能通过列表中的**编辑内部采购**进行修改。

## 步骤二：金额信息

| 字段 | 说明 |
|---|---|
| DPP | 计税基础，最低为 1 |
| 增值税（%） | 0 至 11 |
| 增值税（Rp.） | 依据 DPP 自动计算 |
| PBBKB | 若不适用请填 0 |
| 预扣税代码、预扣税对象名称、预扣税率 | 适用于需代扣预扣税的采购 |
| 其他金额 | 运费、包装费或手续费 |
| 其他金额说明 | 说明该笔其他金额的用途 |

计算方式：

**合计 = DPP + 增值税 + PBBKB + 其他金额**

**支付给供应商 = 合计 − 预扣税**

预扣税自转账金额中扣除，因此步骤四中的数字确实小于此处的合计。这属正常，并非计算
有误。

## 步骤三：附件信息

请勾选实际已持有的单据。**其中两项为必填：**

- 发票
- 采购订单／合同副本

其余为选填：收据、税务发票、付款凭证。

请勿勾选尚未收到的单据。若仍有缺漏，宜以**待处理**状态保存——参见下一节。

## 步骤四：付款信息

供应商收款账户：银行名称、账户名称、账号，以及付款方式（银行转账或虚拟账户）。

底部有两个开关：

- **代付**——当款项由第三方代为垫付时
- **生成付款单**——采购保存后立即生成付款单，无需再从付款菜单进入

## 单据状态

共有两种，所选状态决定其后可执行的操作。

**就绪**——单据齐备，无任何缺漏。

**待处理**——仍有单据或数据未到位。若选择此项，备注栏**必填，10 至 100 个字符**：
请写明尚缺何物，因为他人补交单据时读到的正是这段说明。

日后的差别在于：

- 标记为**待处理**的采购，可通过列表中的**更新状态**补齐。
- 标记为**就绪**的采购则不可。更新状态菜单将被禁用，直接打开该页面也会被拒绝，并
  提示数据已齐备。

因此在确定之前请勿标记为**就绪**。先用待处理、日后补齐，比过早宣告就绪更为稳妥。

## 筛选采购列表

表格上方的筛选标签可多选组合：

**已到期** - **未到期** - **已付清** - **未付清** - **草稿** - **就绪**

搜索框会同时在发票编号、收据、采购订单、供应商名称与税务发票中查找。

点击任意一行可查看明细。最右侧的三点菜单包含更新状态、创建付款与编辑内部采购。

## 若按钮不存在

若本指南所述的菜单不可见，多半是因为它并不属于您的访问权限——并非系统故障。

例如：创建付款仅对具备对外付款权限者显示，而**编辑内部采购**仅对获准修改采购数据者
显示。

若需额外权限，请联系系统管理员。请勿使用他人账户——每一次变更都会以账户所有者的名义
记入活动历史。
