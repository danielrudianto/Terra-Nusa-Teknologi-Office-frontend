# 发票生成器

为没有自有抬头的劳务人员生成发票与收据。

本菜单与销售发票相反。销售发票是公司**向客户**开具的账单；发票生成器生成的是**由
个人供应商向公司**开具的账单单据——通常是确实没有自有发票格式的工头或工匠。

生成的单据仍属于供应商；公司只是提供格式，使其整洁统一。

## 填写

### 信息

| 字段 | 说明 |
|---|---|
| 供应商 | 开具账单的个人供应商 |
| 项目代码 | 承担费用的项目 |
| 城市 | 单据出具地 |
| 截止日期 | 计入本次账单的工作截止日 |
| 发票日期 | 单据上的日期 |
| 单据编号 | 发票编号 |

**截止日期**与发票日期不同。截止日期标明工作计算到何时；发票日期则是单据的开具
时间。两者常相差数日，而界定工作期间的是截止日期。

### 工作明细

按工作类别每项一行：数量、单位、单价与合计。

数量可带小数 —— 最多**四位小数**。这适用于数量本身为小数的工作，例如钻孔
（如 `12.3456`）。整数仍会干净显示（`7`，而非 `7.0000`）。

请按现场约定的表述填写工作说明。供应商核对自己账单时读到的正是这些行——若无法辨认，
他会来询问，从而拖慢付款。

### 账户

供应商的账号与户名会依据其**最近一次使用**的账户自动填入。请重新核对，不要直接采信
——供应商可能更换账户，而转入旧账户的款项不会自行退回。

## 预扣税

选择税务对象代码后，系统会显示三个数字：

| 行项 | 含义 |
|---|---|
| DPP | 计税基础 |
| 代扣预扣税 | 按所选代码税率计算的扣缴额 |
| 实付金额 | 供应商实际收到的金额 |

请告知供应商**实付金额**，而非 DPP。因预扣税产生的差额，是转账到账后最常引发的
疑问。

## 同时记为采购

界面上有**“同时记为采购”**开关。开启后，单据生成的同时系统会以**相同的发票编号**
记录一笔采购，并要求填写采购订单编号。

请使用该功能。生成单据却不记录采购，意味着账单在供应商手中存在、在系统中却不存在
——而这通常要等到供应商催讨一笔从未排入队列的款项时才会暴露。

若关闭该开关，请通过采购菜单手工记录采购，并使用完全相同的发票编号。

## 生成之后

**下载**按钮会生成包含发票与收据的 PDF 文件。交由供应商签署后，再作为凭证附回该笔
采购。
