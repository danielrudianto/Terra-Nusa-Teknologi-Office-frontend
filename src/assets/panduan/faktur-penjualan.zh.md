# 销售发票

就项目工作向客户开具账单。

销售发票是就已完成工作向客户开具的正式账单单据。项目开票以外的收入——利息、特许权
使用费、尾差——通过其他收入记录，而非此处。

## 填写流程

依次三个步骤。

**基本信息 → 金额信息 → 付款信息**

## 步骤一：基本信息

分为两部分：客户数据与发票明细。

| 字段 | 说明 |
|---|---|
| 客户名称 | 从客户列表中选择 |
| 客户地址 | 依据客户自动填入 |
| 客户税号 | 开具税务发票所需 |
| 发票编号 | 格式固定，见下文 |
| 日期 | 发票日期 |
| 项目名称 | 所开票的项目 |
| 说明 | 所开票的工作内容 |
| 工作指令书编号 | 作为依据的工作指令书 |

### 发票编号格式

```
000-INV-XXXX-月份(罗马数字)-年份
```

月份使用罗马数字，而非普通数字。八月为：`VIII`。

## 步骤二：金额信息

| 字段 | 说明 |
|---|---|
| DPP | 计税基础 |
| 增值税与增值税（Rp.） | 卢比金额自动计算 |
| 预扣税代码、预扣税对象名称、预扣税率（%） | 若客户代扣税款 |
| BPJS（Rp.） | 若有 BPJS 扣款 |
| 质保金 | 客户暂扣的账单部分 |
| 合计（Rp.） | 自动计算 |

**质保金**是客户在保修期结束前暂扣的部分金额。它仍计入账单，但尚未收到——因此请勿
自行从 DPP 中扣除。

另有**单独打印？**选项，用于控制该单据是否作为独立文件打印。

## 步骤三：付款信息

选择将收款的 AKN 账户，然后填写付款总额。最后点击**提交并预览**，可在实际保存前查看
结果。

## 发票创建之后

新建的发票尚不能据以收款。顺序如下：

1. 创建发票
2. **确认发票**——核对数据、填写税务发票编号后审批。仅限具备销售发票审批权限者
3. **创建付款**——确认之后方可使用

发票一经确认或删除，确认菜单即被禁用。在发票尚未确认期间，创建付款菜单保持禁用。

## 代扣凭证

若客户代扣税款，其凭证通过**录入代扣凭证**菜单记录。

该菜单仅对状态确实为等待凭证的发票启用。若菜单处于禁用状态，则说明该发票未被代扣
税款，或凭证已经录入。

列表中的搜索框会同时在发票编号、说明、项目与客户名称中查找。
