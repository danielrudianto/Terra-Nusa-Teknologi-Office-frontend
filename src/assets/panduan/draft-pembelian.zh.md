# 采购草稿

在单据齐全之前，先行录入采购数据。

当采购确定会发生、但采购模块所需的资料尚未齐备时使用草稿——例如到期日尚未商定，
或供应商尚未提供账户信息。先在此录入已有内容，其余通过转换后补。

## 何时用草稿，何时直接用采购

若发票、采购订单副本与付款信息均已在手，请直接使用**采购**。

若尚未齐备，请使用**采购草稿**。草稿不强制要求到期日与账户信息，数据便无需在等待
单据期间搁置于个人笔记中。

## 填写草稿

字段少于采购模块：

| 字段 | 必填 | 说明 |
|---|---|---|
| 说明 | 是 | 简要说明采购内容 |
| 税务发票名称 | 否 | 最多 17 个字符 |
| 供应商 | 是 | 从列表中选择 |
| 日期 | 是 | 发票日期或约定日期 |
| 采购订单名称 | 是 | 格式与采购模块相同 |
| 项目 | 是 | 依据采购订单编号自动填入 |
| DPP、增值税、PBBKB | 是 | 可填临时数字，转换时可修改 |

采购订单编号的格式与采购模块完全一致——流水号、单据类型、项目代码，然后是成本
类型。编号匹配后，项目与成本类型会自动填入。

请注意：草稿**不会**询问到期日、附件或收款账户。三者仅在转换时才要求填写。

## 转换为采购

单据齐备后，打开草稿并选择**转换为采购**。

转换过程：已有数据将被沿用，随后系统会要求补齐从未填写的部分——到期日、附件与付款
信息。DPP、增值税等数值在此阶段仍可更正，因此草稿中的临时数字并无妨碍。

转换之后，该记录将作为普通采购继续存在，并遵循采购指南中的全部规则——包括无法撤销
的“就绪”状态。

## 删除草稿

对于已告吹的采购，其草稿应予删除，而非任其堆积。长期悬置的草稿会使列表难以阅读，
也容易与真正等待单据的条目混淆。
