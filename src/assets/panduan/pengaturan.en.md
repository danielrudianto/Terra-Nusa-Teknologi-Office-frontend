# Settings

Adjusting the app's appearance and changing your own password.

Everything on this page applies to your account only. Changing the colour or
text size here changes nothing for anyone else.

## Profile

The name and email address used throughout the app — including the ones shown
in the activity history and on documents you create.

Correct your name here if it's misspelt, because this is the name recorded as
the document's creator. Older history doesn't change with it; what's recorded
there is the name as it stood when that document was made.

## Appearance

### Accent colour

Sets the colour of buttons, checkboxes, switches, and the active-menu marker.
It takes effect immediately, with no need to reload the page.

The colour of text placed on top of the accent is worked out automatically so
it stays readable — dark text on a light accent, white on a dark one. That's
why no combination makes button labels disappear.

### Dark mode

Besides swapping background and text, dark mode also **swaps the entire accent
palette** for lighter versions. That's deliberate: a colour that reads well on
white is too dark to read on black.

So the same accent choice looks different in the two modes, and it should.

### Text size

Three options: Small, Normal, and Large. What changes is the whole app's text
proportionally, not just part of it.

If the screen feels cramped after choosing Large, try pairing it with the
**Compact** density below.

### Density

**Normal** leaves generous spacing between rows. **Compact** tightens it so
more rows fit on one screen — useful on long lists such as purchases and
payments.

### Rows per page

The starting value for every list. It can still be changed per page using the
selector below the table; this only sets where it starts.

Large numbers make pages slower to load when there's a lot of data.

### Language

Indonesian, English, or 中文. Applies to the app's interface.

**Printed documents stay in Indonesian.** Purchase orders, salary slips, and
summary files follow the language of the official document, not the app — so
the same document doesn't change its contents just because its author used a
different interface language.

### Guide button

Turns the floating guide button in the corner on or off. If it's off, the guide
can still be opened from this page.

## Security

### Change password

Requires the old password, the new one, and a repeat. The old password is asked
for as a check that the person changing it really owns the account — not
someone who happened to find the screen open.

The length and composition rules are shown below the field. If the save button
won't light up, it's usually because the repeat doesn't match exactly.

Changing your password **does not sign you out of the session you're in.**

## What isn't set here

Access rights and user levels aren't on this page. Both are set by an
administrator through the **Users** menu and cannot be changed by yourself — if
they could, everyone would simply raise their own level.
