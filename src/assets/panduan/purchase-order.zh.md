# 采购订单

在账单到来之前，向供应商订购物资。

采购订单是发送给供应商的正式订购单据。待货物到达、发票开具后，账单通过**采购**菜单
记录，并引用该采购订单编号。

> 注意：本指南目前涵盖八种采购订单类型——**A、C、D、F、G、5.1.1、5.1.6 与
> 6.3.2**。其余类型仍在开发中，为免误导，
> 暂不编写说明。

## 已涵盖的类型

前五种使用同一张表单，区别仅在末尾的附加字段。后三种形态不同，各自在专属章节中
说明。

| 代码 | 适用 | 附加内容 |
|---|---|---|
| **G** | 项目辅助器具与用品 | 无 |
| **5.1.1** | 资产购置 | 无 |
| **5.1.6** | 办公文件与文具 | 无 |
| **C** | 燃料 | PBBKB、第 22 条预扣税、燃料分析报告 |
| **F** | 材料 | 材料类型与质量检测 |
| **A** | 运输服务 | 运输方式、保险、运输行 |
| **D** | 劳务 | 工资构成及其支付周期 |
| **6.3.2** | 促销物料 | 样品确认、逾期罚金 |

由于 G、5.1.1 与 5.1.6 的表单完全相同，决定选择的是**成本科目**，而非表单外观。现场
辅助物资归入 G，作为财产记录的资产归入 5.1.1，办公所需归入 5.1.6。

## 各类型共通的部分

### 供应商与项目

从列表中选择供应商；名称、地址、城市与税号会自动填入。随后填写承担此次采购的项目
代码。

### 交付方式

两个选项，此选择会改变其下的地址标签：

- **Franco**——货物送达现场。该字段变为*送货地址*
- **Loco**——自行提货。该字段变为*提货地址*

此处选错，会使打印出的条款对运费承担方的表述有误。

### 联系人

两组：**供应商联系人**与**公司联系人**，各含姓名与电话。交付出现问题时，被打印并被
联系的正是这些信息，因此请勿填写无法联系到的人。

### 付款条件

| 代码 | 含义 | 信用期 | 预付 |
|---|---|---|---|
| `CBD` | 交货前付款 | 关闭 | 关闭 |
| `COD` | 货到付款 | 关闭 | 关闭 |
| `PPD` | 预付 | 启用 | 启用 |
| `CR` | 赊账 | 启用 | 关闭 |
| `CRD` | 赊账含预付 | 启用 | 启用 |

**信用期**与**预付**字段会依据所选条件自行启用或关闭。若其中一项被锁定且显示为零，
那本应如此——并非有人忘记填写。

### 物品清单

按物品每项一行：名称、单位、数量与单价。小计与合计自动计算。

### 增值税

**是否含 11% 增值税？**开关决定是否加计增值税。

您输入的单价为**计税基础**——增值税在其之上计算，而非已包含在内。若供应商报价已含
增值税，请先倒算后再录入，否则金额将高出 11%。

### 条款与补充条目

标准条款会依据上述录入内容自动打印——交付方式、付款条件与采购订单类型。无需重复
输入。

**补充条目**部分仅用于标准条款之外的特别约定。若无，请留空。

## C 类——燃料

金额部分有两个附加字段：

- **PBBKB**——按百分比填写，乘以小计
- **第 22 条预扣税**——直接填写金额，而非百分比

请留意二者的区别：一为百分比，一为卢比。填反会使合计严重偏离。

另有**要求提供燃料分析报告与校准证书**的勾选项。勾选后，文件将加印两条附加条款。仅
在确已约定无需时才取消勾选。

## F 类——材料

请先选择**材料类型**，因为该选择决定自动生成的协议条款：

| 选项 | 适用 |
|---|---|
| 混凝土（预拌） | 混凝土供应 |
| 钢材 | 钢材供应 |
| 其他材料 | 上述两者之外的材料 |
| 圆柱体抗压试验 | 混凝土检测服务 |
| 钢材拉伸与弯曲试验 | 钢材检测服务 |

**后两项并非采购物资，而是服务。**其单据将打印为**工作指令书（SPK）**，而非采购
订单。若标题不同请勿意外——这本就如此。

检测服务的填写项为：试件数量、每件单价、报告出具天数，以及试件交付方式。

混凝土与钢材供应设有质量检测勾选项。启用后，将打印“若未通过质量检测，卖方负责更换
货物”的条款。混凝土另有**检测费用承担方**选项：买方或卖方。请事先约定，因为采购订单
一经签发便难以重新协商。

另有两个可选日期：**送达期限**与**付款期限**。若未约定确切日期，请留空。

## A 类——运输服务

用于支付货物运输服务，而非购买货物本身。所开票的是运费。

### 运输行

与其他类型不同，其主要录入项并非货物清单，而是**运输清单**——每趟运输一行。按所开票
的趟次逐行添加。

每行包含运输方式、发货日期、起点、终点与金额。其余字段**随运输方式而变**：

| 方式 | 需填写内容 |
|---|---|
| **陆运** | 车辆、车牌号、司机姓名与身份证号 |
| **海运** | 服务商、集装箱号 |
| **空运** | 服务商、AWB 或运单号 |

车辆仅在陆运时为必填。选择海运或空运后，该字段会自行解除必填——而非留作无法满足的
要求。

数量与单位依照供应商的计费方式。空运常按公斤计费而非包干，因此单位可逐行更改。

### 保险与风险承担

这一部分最常被略过，但它决定了货物受损时由谁承担损失。

**要求提供保险单据**会启用供应商须提交保单的条款。关闭后，该条款完全不会打印——因此
请勿仅因制单时保单尚未收到便将其关闭。

**运输风险**与**装卸风险**须事先约定。采购订单一经签发，二者恰恰在需要时最难重新
协商。

## D 类——劳务

一份工作指令书对应**一名工人**。若承包多人，请分别开具——姓名与工资构成各不相同，将
两人合并的单据无法作为任一方付款的依据。

### 工资构成

工资并非填写为单一数字。请按项目逐行添加——日工资、餐补、津贴、加班——各自带有金额与
支付周期。

之所以分开，是因为周期常常不同：日工资按周支付，而津贴按月支付。若合并，其中之一必
然会以未经约定的周期打印。

### 四种支付周期

| 周期 | 含义 |
|---|---|
| **按周** | 每周于指定日支付 |
| **当月** | 每月于 X 日支付，即当月 |
| **次月** | 每月于次月 X 日支付 |
| **每月两次** | 结算日为 X 日与月末 |

每种周期都有各自的**结算日**——即所计工作期间的截止点。下一期间自次日自动开始，因此
不会有任何一天被重复计算或遗漏。

在每月两次的周期中，第二个结算日始终为**月末**——这正是它区别于普通月度周期之处。支
付日期不以数字写明，因为它取决于结算日落在星期几。

### 条款开关

若干协议条款按约定启用：返程交通、探亲假、设备押运、轮班条款与周日政策。

被关闭者**仍会打印，并加删除线**，而非移除。这是有意为之：阅读者可据此看出该条款是
有意不予采用，而非遗漏。

## 6.3.2 类——促销物料

用于采购促销用品——T恤、保温杯、雨伞等。与涵盖广告服务的 6.3.1 不同。

货物与服务**绝不在同一份订单中混合**。种类在开始时即已确定，并决定整个明细编辑器的
形态。

### 样品确认

**要求样品确认**会启用「须经样品确认后方可批量生产」的条款。

除非确有相反约定，否则请保持启用。缺少该条款，已印制一千件却颜色有误的物料将无据可
退。

### 逾期罚金

默认关闭。若启用，请填写两个数值：**每日千分比**与以百分比表示的**上限**。

上限很重要。若无上限，持续累计的罚金理论上可超过订单本身的金额——而这类条款通常反而
无法执行。

### 交付

由于促销物料属于货物，Franco／Loco 条款、地址与双方联系人均适用——与其他货物采购
相同。

## 签发前检查文件

表单下方有两个按钮，二者显示的是同一份文件。

**预览**在不保存任何内容的前提下打开文件。其编号仍显示*（草稿 — 尚未签发）*，因为
正式编号在保存时才分配。可反复打开；表单内容不会改变。

**创建采购订单**同样会先显示文件，但签发按钮将保持锁定，直至勾选*“我已阅读并核对本
文件的全部内容”*。

该锁定是有意为之。采购订单一经签发，编号即已占用且内容不可更改——唯一的补救是作废
后重新签发，而已发送给供应商的副本无法收回。点击前读完一屏，远比事后作废划算。

## 选错采购订单类型

顶部的**更换类型**按钮可重新打开类型选择器，无需使用浏览器的返回按钮。

若已输入内容，将先出现确认提示——更换类型意味着更换表单，已填内容不会带入。

## G 类的项目代码

G 类附属于特定项目，因此其选择列表中**不提供 PUSAT**。与项目无关的办公费用应通过其他
类型记录。

已使用 PUSAT 代码的旧单据在打开时仍可正常读取——被筛除的只是建议项，而非数据本身。

## 采购订单签发之后

已签发的采购订单编号，将在**采购**菜单记录其账单时使用。格式必须完全一致，因为采购
模块会校验其格式，并依据编号各段填入项目与成本类型。
